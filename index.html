Building

bastion-os — Go (2026)

A bastion that behaves like a protocol-aware proxy instead of an SSH box you log into. It authenticates you against an OIDC provider, authorises the specific target under deny-by-default RBAC, opens its own connection with a managed credential, and records the session — so nobody ends up holding the target's real secrets.

Code

medic — Go (2026)

A one-shot environment health check for on-call triage and CI preflight. It sweeps the host, Docker and your dependencies in a single pass, prints a pass/fail report where every failure carries the command that fixes it, and exits non-zero so it drops straight into a pipeline. One static binary; Swarm checks turn themselves on when the host is a manager.
